
# 168. Excel Sheet Column Title

## Solution Approach 1: Brute Force (Iterative)

### Algorithm

1. Create an empty `StringBuilder`.
2. While `columnNumber > 0`:
   - Decrement `columnNumber` by `1`.
   - Find `remainder = columnNumber % 26`.
   - Convert the remainder to its corresponding character using `'A' + remainder`.
   - Append the character to the `StringBuilder`.
   - Divide `columnNumber` by `26`.
3. Reverse the `StringBuilder`.
4. Return the result as a string.

### Code

```java
class Solution {

    public String convertToTitle(int columnNumber) {

        StringBuilder sb = new StringBuilder();

        while (columnNumber > 0) {

            columnNumber--;

            int rem = columnNumber % 26;

            sb.append((char) ('A' + rem));

            columnNumber /= 26;
        }

        return sb.reverse().toString();
    }
}
```

### Complexity

- **Time:** `O(log26 n)`
- **Space:** `O(log26 n)`

## Solution Approach 2: Better (Recursion)

### Algorithm

1. If `columnNumber == 0`, return an empty string.
2. Decrement `columnNumber` by `1`.
3. Recursively compute the title for `columnNumber / 26`.
4. Append the current character using `'A' + (columnNumber % 26)`.
5. Return the concatenated result.

### Code

```java
class Solution {

    public String convertToTitle(int columnNumber) {

        if (columnNumber == 0)
            return "";

        columnNumber--;

        return convertToTitle(columnNumber / 26)
                + (char) ('A' + columnNumber % 26);
    }
}
```

### Complexity

- **Time:** `O(log26 n)`
- **Space:** `O(log26 n)`

---

## Solution Approach 3: Optimal (Iterative)

### Algorithm

1. Create an empty `StringBuilder`.
2. Repeat while `columnNumber > 0`:
   - Convert to 0-based indexing by decrementing `columnNumber`.
   - Append the character corresponding to `columnNumber % 26`.
   - Update `columnNumber = columnNumber / 26`.
3. Reverse the constructed string.
4. Return the final Excel column title.

### Code

```java
class Solution {

    public String convertToTitle(int columnNumber) {

        StringBuilder ans = new StringBuilder();

        while (columnNumber > 0) {

            columnNumber--;

            ans.append((char) ('A' + columnNumber % 26));

            columnNumber /= 26;
        }

        return ans.reverse().toString();
    }
}
```

### Complexity

- **Time:** `O(log26 n)`
- **Space:** `O(log26 n)`
